## 🎯 Learning Path

```
Basics (what & how)
  → What is GenAI → LLMs → Prompting → Embeddings
        │
Intermediate (build with it)
  → RAG → Fine-tuning → Agents → Bedrock
        │
Advanced (run it in production)
  → LLMOps → Security → Advanced RAG
```

## 🔑 Key Concepts Covered

- LLMs, tokens, foundation models, Transformers
- Prompt engineering (zero/few-shot, chain-of-thought)
- Embeddings, vector databases, semantic search
- RAG — grounding LLMs in your data
- Fine-tuning (LoRA/QLoRA/PEFT)
- AI agents, tool use, ReAct pattern
- AWS Bedrock (Knowledge Bases, Guardrails, Agents)
- LLMOps — evaluation, monitoring, cost control
- GenAI security (OWASP Top 10 for LLMs), responsible AI
- Advanced RAG (hybrid search, re-ranking, agentic RAG)
